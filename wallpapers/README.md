# Animated Black Hole Wallpaper

A self-contained, lightweight animated SVG wallpaper for the InnyGrOS / IntegerOS desktop, featuring a violet-and-cyan black hole and InnygrCorp + Team Blacklight branding.

## File

- `InnyGrOS-BlackHole-Animated.svg` — 1920×1080 SVG wallpaper with animated accretion-disk highlights and twinkling stars.

## Using it in KDE Plasma

1. Copy the SVG to `~/.local/share/wallpapers/` (create the directory if needed).
2. Open **Configure Desktop and Wallpaper**.
3. Choose the image wallpaper plugin and select the SVG.

SVG animation support depends on the selected wallpaper renderer and Plasma version. If your current wallpaper renderer displays the SVG but does not animate it, use a compatible animated-SVG/video wallpaper plugin or convert the design to a video loop. The SVG is intentionally self-contained and does not load remote resources.

The animation is decorative and does not change system settings.
